# Android Player Assets Guide

This directory contains the audio track and haptic waveform loaded by `MainActivity`:

- **`audio.mp3`**: The audio file played during playback (can be any MP3/WAV file).
- **`waveform.json`**: The 10ms-precision event queue and waveform timings generated by `audio2haptic.py`.
- **`waveform_compressed.json`**: RLE-compressed waveform.
- **`amplitude.json` / `timing.json` / `time_points.json`**: Raw arrays for standard Android `VibrationEffect.createWaveform()`.

### How to use your own song:
1. Run the Python generator on your music:
   ```bash
   python3 generator/audio2haptic.py path/to/mysong.flac -o output/mysong
   ```
2. Convert your song to MP3 (or copy the MP3):
   ```bash
   ffmpeg -i path/to/mysong.flac -codec:a libmp3lame -b:a 192k audio.mp3
   ```
3. Copy `output/mysong/waveform.json` and `audio.mp3` into this `assets/` folder.
4. Run `bash build_apk.sh` to compile and install your custom APK!
